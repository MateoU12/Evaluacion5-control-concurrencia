## Objetivo
Comparar diferentes formas de controlar el acceso
de varios hilos a un mismo contador.


## Desarrollo
Se crearon tres contadores:


1. Contador sin control de concurrencia.
2. Contador con synchronized.
3. Contador con AtomicLong.


## Prueba realizada
Se creó una prueba con 1.000 tareas y 20 hilos
para comparar los resultados de los tres contadores.


## Resultados
La prueba permite observar cuántos intentos se
registraron correctamente, si hubo errores y cuánto
tiempo tardó cada estrategia.


Los resultados se deben obtener ejecutando el programa.
